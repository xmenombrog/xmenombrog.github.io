            Overview
          
    
          
    How a request is handled
    
        
    
        
    
          
    Every request passes CORS, then the rate limiter, then the search route, which tries the cheapest lookup first.
    
          
      
            
    • 
              
              CORS on every route, so a browser on any origin can call it.
            
      • 
            
    • 
              
              Rate limiting with express-rate-limit: 100 requests per IP per minute, then 429.
            
      • 
            
    • 
              
              Lookup by ID on Answer.Question_ID, with an index on the collection.
            
      • 
            
    • 
              
              Lookup by text as a fallback, matching the exact question.
            
      • 
            
    • 
              
              AI fallback chosen in config.ini: Gemini 2.0 Flash, a local Ollama model (gemma3), or none.
            
      • 
            
    • 
              
              Helpful failures: 400 for a missing query, an empty list when Ollama isn’t running.
            
      • 
          
    
        
    
      
    
    
    

    
    
      
    
        
    
          
    
            
            Code
          
    
          
    Under the hood
    
        
    
        
    
          
    A small Express app split by responsibility, plus a separate ingest tool that fills the database.
    
          
    
            
    
              serverV2/
              JavaScript · Node.js
            
    
            
    
              
    
                
    index.js
    
                
    Express app: CORS, the rate limiter and the /search route. Connects to MongoDB before listening, and prints a daily Bible verse on startup.
    
              
    
              
    
                
    routes/search.js
    
                
    The search logic: questionId, then questionText, then the configured AI provider.
    
              
    
              
    
                
    db/mongo.js
    
                
    MongoDB Atlas connection and indexes on the questions collection.
    
              
    
              
    
                
    ai/Gemini.jsai/ollama.js
    
                
    Prompt the model to answer only from the given choices, one answer per line.
    
              
    
              
    
                
    Database/
    
                
    A Discord bot and parser that read question-and-answer posts from a channel into MongoDB with Mongoose, resuming from the last fetched message.
    
              
    
              
    
                
    config.inirun.batsetup.bat
    
                
    Provider switch and Windows scripts to install and start the server.
